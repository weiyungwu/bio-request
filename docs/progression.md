# 等級、EXP 與成就設計

BIO QUEST 的等級不依「答題次數」計算，而是採用 **EXP 經驗值制 + 學習成就制**：學生不能只靠重複刷簡單題目升級，必須真正完成課程、理解知識並通過測驗。

各節標註實作狀態，未實作的部分由對應任務依本文件實作。

## 1. 等級制度（已實作：`src/utils/level.ts`，TASK-003）

初版 10 個等級，每升一級需要累積更多 EXP。Lv.10 為最高等級，超過門檻的 EXP 仍累積，但不再升級。

| 等級  | 稱號       | 累積 EXP |
| ----- | ---------- | -------- |
| Lv.1  | 生物新手   | 0        |
| Lv.2  | 見習探索員 | 100      |
| Lv.3  | 細胞見習生 | 250      |
| Lv.4  | 細胞探索員 | 450      |
| Lv.5  | 生物研究員 | 700      |
| Lv.6  | 生物專家   | 1,000    |
| Lv.7  | 生命觀察家 | 1,400    |
| Lv.8  | 進階研究員 | 1,900    |
| Lv.9  | 生物學者   | 2,500    |
| Lv.10 | 傳奇探索者 | 3,200    |

等級稱號刻意不與 FR-07 徽章同名（徽章「初級探索員」「生物大師」另有取得條件），避免把等級和成就混為一談（§5）。

首頁顯示範例（520 EXP）：

- Lv.4 細胞探索員
- 520 EXP
- 進度條：本級區間 450 → 700 EXP
- 距離 Lv.5 還差 180 EXP

## 2. EXP 取得規則（已實作：`src/utils/exp.ts`、`src/stores/progress.ts`，TASK-012／015）

| 學習行為         | EXP 獎勵 | 限制         |
| ---------------- | -------- | ------------ |
| 完成一個知識單元 | +10      | 每單元首次   |
| 完成互動小遊戲   | +15      | 每遊戲首次   |
| 測驗 60～79 分   | +10      | 每次         |
| 測驗 80～89 分   | +20      | 每次         |
| 測驗 90～99 分   | +30      | 每次         |
| 測驗 100 分      | +40      | 每次         |
| 首次通關關卡     | +30      | 每關一次     |
| 完成錯題補強     | +10      | 每組錯題首次 |

特別規則：

- 同一個知識單元重複閱讀，不重複給 EXP。
- 同一個小遊戲重複玩，不重複給首次完成獎勵。
- 測驗可以重複取得 EXP，但有每日上限。
- 首次通關獎勵不能透過重玩重複取得。

實作細節（TASK-015）：

- 知識單元：讀完該單元最後一個知識點、往下一步時發放（第一關單元 A、B、C、D；單元 D 是 2026-11-11 依課本新增）。
- 互動小遊戲：第一關兩個——細胞器配對、植物還是動物？（細胞互動圖是探索任務，不計入）。
- 完成錯題補強（Human 決定）：「一組」= 一個關卡。該關錄入錯題本的題目**全部重新答對**時 +10，每關一次；只「標記已熟悉」而沒有重新答對的題目不算。
- 首次完成類獎勵記在保存資料的 `claimed`（如 `unit:bio-01:lesson-01`、`game:bio-01:matching`、`review:bio-01`），領過就不再發。

## 3. 防刷分機制（已實作，TASK-015）

| 機制              | 規則                 |
| ----------------- | -------------------- |
| 每日測驗 EXP 上限 | 100 EXP              |
| 首次完成獎勵      | 每個活動只能領取一次 |
| 重複測驗          | 只計算測驗分數獎勵   |
| 測驗最低門檻      | 60 分以下不給 EXP    |
| 錯題補強          | 重新答對才給獎勵     |
| 關卡獎勵          | 每關只能領取一次     |

實作時需確認的細節：

- 「每日」以學生裝置的本地日期計算（台灣為 Asia/Taipei）。
- 每日上限只限制測驗分數獎勵，不限制首次完成類獎勵。
- 單次測驗獎勵若會超過當日剩餘額度，只發放剩餘額度。

實作：每筆學習紀錄保存實際發放的測驗 EXP（`records[].exp`），以裝置本地日期加總當天已發放量；結果頁會說明「今天的測驗 EXP 已達上限」。

弱點練習（v1.1 Phase 2，Human 決定 2026-11-11）：一次 5 題，依分數照測驗級距給 EXP（60～79 → 10 … 100 → 40），和關卡測驗**共用**每日 100 EXP 上限；答錯的題目加進錯題本。練習不是關卡測驗：不影響通關、最高分、最近學習紀錄與徽章。紀錄存在 `practice[]`（實際發放的 EXP 在 `practice[].exp`）。

## 4. 八個關卡的等級成長（設計目標，供 TASK-015 驗證規則）

等級是鼓勵機制，**不作為解鎖下一關的條件**。

| 關卡 | 完成內容   | 預期累積 EXP |
| ---- | ---------- | ------------ |
| 01   | 生命與細胞 | 100～150     |
| 02   | 細胞分裂   | 250～350     |
| 03   | 生物分類   | 400～550     |
| 04   | 植物生理   | 600～750     |
| 05   | 人體消化   | 850～1,000   |
| 06   | 人體生理   | 1,100～1,350 |
| 07   | 神經與生殖 | 1,450～1,750 |
| 08   | 遺傳與生態 | 1,900～2,300 |

完成八關約可達 Lv.7～Lv.8；其餘等級透過錯題複習、挑戰題與精熟練習取得。

驗算（第一關，全部首次完成）：4 個知識單元 × 10 + 2 個小遊戲 × 15 + 測驗最高 40 + 首次通關 30 = 140 EXP，落在 100～150 的目標內（加單元 D 前是 130）。

上表是「每關完成一次」的估算。重複挑戰測驗仍可取得分數獎勵（每天最多 100 EXP），所以多次練習的學生會超過這個目標，這是刻意的：重複練習只換得測驗獎勵，不會重複領首次完成類獎勵。

## 5. 等級、徽章與精熟度分開

| 系統           | 代表意義         | 取得方式                       | 狀態                     |
| -------------- | ---------------- | ------------------------------ | ------------------------ |
| 等級 Level     | 學習參與程度     | 累積 EXP                       | 已實作（§1）             |
| 徽章 Badge     | 特定學習成就     | 達成指定條件（spec.txt FR-07） | 已實作（TASK-015，見下） |
| 精熟度 Mastery | 知識真正學會多少 | 多次測驗與答題表現             | MVP 規格未包含，MVP 之後 |

例：Lv.5 代表累積了足夠的學習經驗；細胞專家徽章代表完成細胞相關任務；細胞精熟度 90% 代表最近相關題目的答題表現良好。分開設計，避免出現等級很高、但考試都不會的情況。

徽章條件（`src/utils/achievements.ts`，依保存的進度判斷，每個徽章只發一次）：

| 徽章       | 條件                                                |
| ---------- | --------------------------------------------------- |
| 初級探索員 | 完成第一關                                          |
| 細胞專家   | 完成第 1、2 關（Human 決定：細胞相關關卡 = 這兩關） |
| 答題高手   | 單次測驗達 90 分                                    |
| 完美通關   | 單次測驗 100 分                                     |
| 生物大師   | 完成全部八關                                        |

MVP 只開放第一關，細胞專家與生物大師要等後續關卡上線才拿得到。
